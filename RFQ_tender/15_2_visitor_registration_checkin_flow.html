15.2 Visitor Registration & Check-in Flow

Complete Visitor Journey from Arrival to Departure

flowchart TD
    Start([Visitor Arrives]) --> Check{Already Registered?}

    Check -->|No| PreRegister[Pre-register Online or Walk-in]
    Check -->|Yes| Search[Search Visitor]

    PreRegister --> RegForm[Fill Registration Form]
    RegForm --> RegData[Visitor Data Entry]

    RegData --> Validate{Validate Data}
    Validate -->|Invalid| RegForm
    Validate -->|Valid| CheckDuplicate{Visitor Exists?}

    CheckDuplicate -->|Yes| Update[Update Existing Visitor]
    CheckDuplicate -->|No| Create[Create New Visitor]

    Update --> SelectHost[Select Host]
    Create --> SelectHost

    Search --> Found{Visitor Found?}
    Found -->|No| PreRegister
    Found -->|Yes| SelectHost

    SelectHost --> NotifyHost[Notify Host]

    NotifyHost --> HostDecision{Host Approval}

    HostDecision -->|Auto-approve| AutoApproved[Visit Auto-Approved]
    HostDecision -->|Manual| Pending[Visit Status: Pending]
    HostDecision -->|Reject| Rejected[Visit Status: Rejected]

    Pending --> HostAction{Host Action}
    HostAction -->|Approve| Approved[Visit Status: Approved]
    HostAction -->|Reject| Rejected

    AutoApproved --> GenerateOTP[Generate OTP]
    Approved --> GenerateOTP

    GenerateOTP --> SendOTP[Send OTP via Email/SMS]

    SendOTP --> VisitorArrives[Visitor Arrives at Branch]

    VisitorArrives --> VerifyMethod{Verification Method}

    VerifyMethod -->|OTP| OTPVerify[Verify OTP]
    VerifyMethod -->|Face ID| FaceVerify[Face Recognition]
    VerifyMethod -->|RFID| RFIDVerify[Scan RFID Card]
    VerifyMethod -->|QR Code| QRVerify[Scan QR Code]

    OTPVerify --> OTPCheck{OTP Valid?}
    OTPCheck -->|No| RetryOTP[Retry OTP - Max 3 attempts]
    RetryOTP --> OTPCheck
    OTPCheck -->|Yes| CheckIn

    FaceVerify --> FaceCheck{Face Match?}
    FaceCheck -->|No| ManualVerify[Manual Verification]
    FaceCheck -->|Yes| CheckIn

    RFIDVerify --> RFIDCheck{Card Valid?}
    RFIDCheck -->|No| InvalidCard[Invalid Card Alert]
    RFIDCheck -->|Yes| CheckIn

    QRVerify --> QRCheck{QR Code Valid?}
    QRCheck -->|Expired| QRExpired[QR Expired]
    QRCheck -->|Used| QRUsed[QR Already Used]
    QRCheck -->|Valid| CheckIn

    ManualVerify --> CheckIn
    QRExpired --> GenerateOTP
    QRUsed --> SecurityAlert[Security Alert]
    InvalidCard --> SecurityAlert
    Rejected --> NotifyReject[Notify Visitor: Rejected]

    CheckIn[Check-in Visitor] --> AssignBadge[Assign Access Badge]

    AssignBadge --> NotifyCheckin[Notify Host]

    NotifyCheckin --> ActiveVisit[Visit Status: Active]

    ActiveVisit --> MonitorVisit[Monitor Visit]

    MonitorVisit --> VisitorLeaves[Visitor Departs]

    VisitorLeaves --> CheckOut[Check-out Visitor]

    CheckOut --> ReturnBadge[Return Badge]
    ReturnBadge --> VisitComplete[Visit Status: Completed]

    VisitComplete --> CalculateDuration[Calculate Duration]
    CalculateDuration --> UpdateStats[Update Statistics]

    UpdateStats --> Feedback[Optional Feedback]

    Feedback --> Archive[Archive Visit Record]
    Archive --> End([Visit Complete])

    NotifyReject --> Archive

📋 Description

This diagram shows the complete visitor management workflow:

  • Registration: Pre-registration online or walk-in registration
  • Host Approval: Manual or auto-approval process
  • Verification Methods: OTP, Face Recognition, RFID, or QR Code
  • Check-in Process: Badge assignment and host notification
  • Visit Monitoring: Real-time tracking with overstay alerts
  • Check-out: Badge return and visit archival
