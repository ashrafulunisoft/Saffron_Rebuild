    DeleteVisitor -->|No| VisitorList

    PendingVisits --> PendingAction{Pending Action}
    PendingAction -->|Approve| AdminApprove[Approve Visit]
    PendingAction -->|Reject| AdminReject[Reject Visit]

    ActiveVisits --> MonitorActive[Monitor Active Visitors]
    MonitorActive --> ForceCheckout{Force Check-out?}

    CheckinMgmt --> CheckinList[Check-in Log]
    CheckinList --> ViewTimestamps[View Timestamps and Duration]

    RoleMgmt --> RoleActions{Role Actions}
    RoleActions -->|Create Role| CreateRole[Create Role]
    RoleActions -->|Assign Role| AssignRole[Assign Role]

    AssignRole --> UserSelect[Select User]

    Reports --> ReportType{Report Type}
    ReportType -->|Visitor Stats| VisitorStats[Visitor Statistics]
    ReportType -->|Visit Report| VisitReport[Visit Report]
    ReportType -->|Export CSV| ExportCSV[Export CSV]

    VisitorStats --> ViewStats[View Statistics]

    VisitReport --> GenerateReport[Generate Report]
    GenerateReport --> DisplayReport[Display Report]

    ExportOption -->|Yes| ExportCSV
    ExportOption -->|No| AdminMenu

    LiveDashboard --> LiveView[Live Dashboard View]
    LiveView --> WebSocket[WebSocket Connection]
    WebSocket --> LiveMetrics[Live Metrics]

    Settings --> SettingOptions{Settings Options}
    SettingOptions -->|General| GeneralSettings[General Settings]
    SettingOptions -->|Notifications| NotificationSettings[Notification Settings]
    SettingOptions -->|Security| SecuritySettings[Security Settings]

📋 Description

This diagram illustrates all administrative functions:

  • Visitor Management: Create, view, search, edit, and delete visitors
  • Visit Management: Approve, reject, and monitor visits
  • Role Management: Create, assign, and remove user roles
  • Reports: Statistics, visit reports, and CSV exports
  • Live Dashboard: Real-time monitoring via WebSocket
  • Settings: General, notifications, and security configurations
